# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, and business trends.

The project demonstrates an end-to-end data analytics workflow using:

- Python for data cleaning and exploratory data analysis
- SQL for data analysis and answering business questions
- Power BI for interactive data visualization and dashboard creation

The analysis helps understand customer behavior and provides insights that can support data-driven business decisions.

## Project Workflow

The project follows these major steps:

### 1. Data Preparation & Exploratory Data Analysis

Python was used to:

- Import the customer shopping dataset
- Understand the structure of the data
- Identify missing values
- Clean and transform the data
- Perform exploratory data analysis
- Identify important patterns and trends

### 2. SQL Data Analysis

SQL was used to analyze the cleaned dataset and answer business-related questions.

The analysis includes:

- Customer segmentation
- Purchase behavior
- Product preferences
- Customer loyalty
- Sales-related patterns
- Aggregated business metrics

SQL concepts used include:

- `SELECT`
- `WHERE`
- `GROUP BY`
- `ORDER BY`
- Aggregate functions
- `JOIN`
- CTEs
- Subqueries

### 3. Power BI Dashboard

Power BI was used to create an interactive dashboard for visualizing the analysis.

The dashboard presents:

- Key Performance Indicators (KPIs)
- Customer behavior
- Purchase patterns
- Product trends
- Customer segments
- Interactive charts and filters

### 4. Business Insights

The analysis was used to identify meaningful patterns in customer shopping behavior and translate them into business insights.
